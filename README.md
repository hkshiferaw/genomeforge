# GenomeForge

A bioinformatics pipeline toolkit, built as a hands-on learning project.

## Status

Early scaffolding stage (Phase 0 of a structured curriculum). No pipeline
functionality exists yet — this repo currently contains just the installable
package skeleton and a `hello()` sanity-check function.

## Installation

```bash
git clone <repo-url>
cd genomeforge
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```
